# MediMate 설계 문서

디지털 소외계층(시각장애인·고령층)을 위한 OCR·AI 기반 복약 관리 플랫폼 **메디메이트(MediMate)** 의 요구사항 및 기술 설계 문서입니다.
2026-2 알파프로젝트 신청서와 기획안을 바탕으로, 외부 API를 아래 두 가지로 확정한 내용을 반영했습니다.

| 구분 | 기획안(2026-07) | 확정안(본 문서) |
|---|---|---|
| OCR | Google ML Kit OCR | **NAVER CLOVA OCR General (프리미엄)** |
| AI (텍스트 정제·구조화, 알약 비전) | ChatGPT 3.5 API | **AWS Bedrock – Claude Fable 5.1** |
| 알약 식별 | 비전 분석 (미정) | 기존 `pill-classifier`(고전 CV + 임베딩) **+ Claude 비전 보조** |
| 로그인·DB | Firebase 로그인·DB | **Firebase 로그인 + 사용자 데이터는 Firestore, 서버 DB는 공용 데이터만** (2026-11-08 변경, 기술설계서 ADR-10) |
| 보호자 기능 | 1차 개발 범위 | **v2 추후 업데이트로 이동** |

## 릴리스 구분

| 버전 | 범위 | 문서 위치 |
|---|---|---|
| **v1** (학기 내 출시) | 로그인 3종·재설치 복원, 약봉투·처방전 인식 등록, 낱알 식별, 약품 정보, 복약 알림·복용 체크, 영양제 추천, 음성·접근성 | 각 문서 본문 |
| **v2** (추후 업데이트) | 보호자 연결, 복용 현황 원격 확인, 미복용 푸시(FCM 도입), 백업 알림 | 01 §11, 02 §14, 04 §11 |

## 문서 규칙

- 요구사항 ID: `FR-<영역>-<번호>`(기능), `NFR-<영역>-<번호>`(비기능). 설계·테스트·이슈에서 이 ID를 참조합니다.
- 우선순위: **P0**(중간평가 전 필수), **P1**(출시 전 필수), **P2**(여유 시).
- "확인 필요"로 표시된 항목은 착수 시 콘솔·공식 문서에서 값을 확인한 뒤 문서를 갱신합니다.

## 데이터 출처

- **AI 허브 「경구약제 이미지 데이터」**: 임베딩 모델 학습과 실제 사진 평가에 썼고, `docs/figures`의 그림 일부(`07_처리예시.png`의 ① 실제 촬영 사진 등)에 사진이 들어 있습니다. 원본 데이터는 이 저장소에 없으며, AI 허브에서 신청해 받아야 합니다.
  > 이 프로젝트는 과학기술정보통신부의 재원으로 한국지능정보사회진흥원의 지원을 받아 구축된 "경구약제 이미지 데이터"를 활용하여 수행되었습니다. 이 프로젝트에 활용된 데이터는 AI 허브([aihub.or.kr](https://aihub.or.kr))에서 내려받을 수 있습니다.
- **식품의약품안전처 「의약품 낱알식별 정보」, 「의약품개요정보(e약은요)」** (공공데이터포털 [data.go.kr](https://www.data.go.kr)): 알약 참조 사진·모양·색·각인 DB와 약 설명에 썼습니다. 그림의 ③ 식약처 참조 사진도 여기서 나왔습니다.
- **미국 국립의학도서관(NLM) C3PI 알약 사진** ([data.lhncbc.nlm.nih.gov/public/Pills](https://data.lhncbc.nlm.nih.gov/public/Pills/)): 폰 사진 조건의 평가에만 썼습니다.
